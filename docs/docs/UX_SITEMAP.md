# Bonram Rentals - UX Sitemap

This sitemap outlines the Information Architecture for the Bonram Rentals portal, optimized for "Institutional Luxury" and dual-entry paths (B2B/Government & B2C/Luxury).

## 1. Global Navigation
- **Home**: The "stunning" first impression.
- **Equipment Catalog**: Searchable/categorical view of all hire items.
- **Services**: Specialized solutions (Shuttle, Catering Support, Event Planning).
- **Our Track Record**: Institutional references & the "Presidential" story.
- **Request a Quote**: Primary CTA (floating or persistent).
