# Bonram Rentals - UX Design System

This document translates the "Institutional Luxury" brand into a consistent set of digital design tokens and components.

## 1. Core Palette
| Token                | HEX       | Usage                                                    |
| :------------------- | :-------- | :------------------------------------------------------- |
| **Navy (Primary)**   | `#1e3a5f` | Backgrounds, Headers, Primary CTA, Authority statements. |
| **Gold (Accent)**    | `#d4af37` | Highlights, Icons, Labels, Premium indicators.           |
| **White (Clean)**    | `#ffffff` | Primary text, Modern whitespace, Professional cards.     |
| **Mist (Secondary)** | `#f5f5f5` | Subtle backgrounds, input fields, containers.            |
| **Charcoal (Body)**  | `#333333` | Standard body copy for high readability.                 |

## 2. Typography
- **Headlines**: `Montserrat` (Bold, Sans-serif) - Authoritative, strong, "Presidential".
- **Body Text**: `Open Sans` (Regular, Sans-serif) - Approachable, clean, highly readable.
- **Accents**: `Montserrat` (Italic or Light) - Refined "state function" details.

## 3. UI Components

### 3.1 The "Authority" Header
- Sticky navigation.
- Centered or Left-aligned logo with High-Margin whitespace.
- Gold "Request a Quote" CTA (Right).

### 3.2 The "Institutional" Feature Card
- Clean white background.
- Subtle drop-shadow (`0 4px 6px rgba(0,0,0,0.05)`).
- 2px Gold border-bottom on hover (Interactivity).

### 3.3 The "Hero" Stage
- Full-bleed background imagery with a `40% Navy Overlay`.
- Centered typography in White/Gold.
- Micro-animations: Fade-in on load.

## 4. Imagery Language
- **Warmth**: Use "Golden Hour" lighting in concepts.
- **Precision**: Focus on clean industrial lines.
- **Context**: Always show South African landscapes or high-end venue interiors.
