## Design Guidelines

### Color Scheme:
- **Primary:** Navy Blue (#1e3a5f or similar)
- **Accent:** Gold (#d4af37)
- **Supporting:** White, Light Grey

### Typography:
- **Headings:** Bold, modern sans-serif (e.g., Montserrat, Raleway)
- **Body:** Clean, readable sans-serif (e.g., Open Sans, Lato)
- **Size:** Large enough for projection viewing

### Layout Principles:
- Clean, uncluttered slides
- High-quality images
- Consistent branding throughout
- Navy blue/gold color scheme on every slide
- Logo on every slide (bottom right corner)

### Image Usage:
- Use high-resolution images
- Apply navy blue overlay (20-40% opacity) when text needs to stand over images
- Maintain consistent image treatment throughout

---

## Presentation Length

**Full Version:** 18 slides (~15-20 minutes)  
**Short Version:** Slides 1, 2, 5, 8, 10, 13, 18 (~7-10 minutes)  
**Executive Summary:** Slides 1, 2, 5, 13, 18 (~5 minutes)

## Additional Notes for Tender Applications

- Slide 5: Add specific client references if tender requires
- Slide 16: Add specific certifications requested in tender (BEE, ISO, etc.)
- Insert compliance slides as needed between slides 16-17
- Add pricing/quote slide if tender format requires

### Supporting Documents:
- Attach detailed equipment specifications
- Include copies of company registration
