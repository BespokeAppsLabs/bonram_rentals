## Image Optimization Notes

### For Print (PDF, Brochures):
- Use high-resolution originals
- CMYK color profile for professional printing
- 300 DPI minimum

### For Digital (Website, PowerPoint):
- Optimize file sizes for web (compress PNGs)
- RGB color profile
- 72-150 DPI acceptable
- Responsive sizing for mobile

### For Social Media:
- Square crops for Instagram
- 16:9 crops for LinkedIn/Facebook
- Add navy blue borders or overlays for branding consistency
- Include logo watermark subtly
